# 2. Check umask, create new file, run ls -l and explain
umask
touch test_umask.txt
ls -l test_umask.txt

# Explanation for umask: 
# When a new file is created, Linux gives it a base permission of 666 (rw-rw-rw-).
# The system's umask value (commonly 0022) acts as a filter and is subtracted from the base.
# For example: 666 - 022 = 644. This results in the default permission rw-r--r-- 
# as seen in the 'ls -l' output.
